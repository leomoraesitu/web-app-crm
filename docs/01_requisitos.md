# Requisitos do Sistema

## Requisitos Funcionais (RF)

### RF-01 – Autenticação
O sistema deve permitir login seguro via Firebase Authentication.

### RF-02 – Gestão de Leads
Usuários podem criar, editar e excluir leads associados à sua empresa.

### RF-03 – Kanban
Leads devem ser organizados por status em formato Kanban.

### RF-04 – Gestão de Colaboradores
Usuários administradores podem convidar, editar permissões e remover colaboradores.

---

## Requisitos Não Funcionais (RNF)
- Segurança: isolamento total entre empresas
- Performance: consultas otimizadas por índices
- Usabilidade: interface responsiva
- Escalabilidade: estrutura preparada para crescimento
