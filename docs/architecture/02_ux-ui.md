# UX / UI

## Princípios
- Clareza
- Simplicidade
- Consistência
- Responsividade

## User Flow Principal
Login → Dashboard → Kanban → Lead → Gestão de Time

## Responsividade
- Desktop: menu lateral expandido
- Tablet: menu recolhido
- Mobile: menu inferior

## Design System
- Cores neutras com destaque para status
- Tipografia legível
- Componentes reutilizáveis
