# Visão Geral do Projeto

## Contexto
Este projeto simula um CRM SaaS real, com suporte a múltiplas empresas, usuários e permissões, utilizando FlutterFlow e Firebase.

## Objetivos
- Demonstrar capacidade técnica fullstack low-code
- Aplicar engenharia de software em ambiente realista
- Criar material sólido para portfólio profissional

## Escopo Inicial (v1)
Incluído:
- Autenticação
- Leads
- Kanban
- Dashboard
- Gestão de usuários

Fora de escopo:
- Integrações externas
- Automação de marketing
- Relatórios avançados
